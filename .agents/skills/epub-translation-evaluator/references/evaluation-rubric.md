# 翻譯品質評分標準 (Evaluation Rubric)

在進行 V1 與 V2 譯文比對時，請嚴格遵守以下 1-5 分的評分標準：

## 5 分 (完美 - Perfect)
* **語意與語氣**：翻譯精準，且語氣完全符合 `style_profile.md` 的設定，讀起來自然流暢，毫無「翻譯腔」。
* **完整度**：沒有任何漏翻。
* **雙語模式**：(若啟用) 原文與譯文段落交錯完美，且加上了正確的 CSS class。

## 4 分 (良好 - Good)
* **語意與語氣**：整體通順，但有少數幾個句子略顯生硬，或有極少數不太符合 Style Profile 的微小瑕疵。
* **完整度**：沒有明顯漏翻，或是漏翻的內容完全不影響上下文（例如無意義的標籤內容）。

## 3 分 (尚可 - Acceptable)
* **語意與語氣**：能看懂意思，但有明顯的「機翻感」，或是語氣與 Style Profile 明顯不符（例如該用輕鬆語氣卻用了學術語氣）。
* **完整度**：有少數漏翻，但不影響整體章節的理解。

## 2 分 (差劣 - Poor)
* **語意與語氣**：有嚴重的翻譯錯誤導致扭曲原意，或名詞翻譯前後不一致。
* **完整度**：有大段落的漏翻。

## 1 分 (災難 - Disastrous)
* **語意與語氣**：胡言亂語或完全未翻譯。
* **結構破壞**：嚴重破壞了不該翻譯的 HTML 標籤（如將 `class` 內容翻譯成中文，或弄壞圖片路徑）。

## 舉證規範 (Chain of Thought Requirement)

當你給出評分時，**絕不能憑空給分**。你必須在報告中列出具體證據。
請使用以下格式列出至少 1-2 個關鍵差異或瑕疵，來佐證你的評分：

> **證據 1：(針對 V1 的扣分)**
> 原文: `<p>He kicked the bucket.</p>`
> V1 譯文: `<p>他踢了水桶。</p>`
> 理由: V1 未察覺這是片語，直譯導致語意錯誤。

> **證據 2：(針對 V2 的加分)**
> 原文: `<p>He kicked the bucket.</p>`
> V2 譯文: `<p>他翹辮子了。</p>`
> 理由: V2 正確翻譯出片語，且符合 Style Profile 中「口語化」的要求。
